Kod-Asistan v0.1 (Code Assistant v0.1)

Project Purpose
The purpose of this project is to design a simple digital assistant that helps users with everyday tasks, such as performing calculations, greeting users, and responding to basic commands.

Kod-Asistan aims to provide a user-friendly experience by processing user input and generating appropriate responses.

Project Goals
The project is planned to evolve through the following versions:

v1.0 – Smart Menu: Introduce a menu system that allows users to select available functions easily.
v2.0 – Data Storage: Add the ability to save and retrieve user data.
v3.0 – Advanced Assistant: Expand the assistant's capabilities with additional commands and improved input handling.
v4.0 – Personalized Experience: Provide more personalized responses and customizable settings.
Project Scope
The initial version of Kod-Asistan focuses on basic user interaction, simple calculations, greeting messages, and conditional decision-making.

The project also includes a CRITICAL THRESHOLD mechanism. This mechanism checks whether an input value reaches or exceeds a predefined threshold and determines the appropriate action based on the result.

CRITICAL THRESHOLD Logic
The assistant first receives an input value from the user and compares it with a predefined critical threshold.

If the input value is below the threshold, the assistant continues with the normal process.
If the input value is equal to or greater than the threshold, the assistant activates the predefined critical response, such as displaying a warning message or performing an appropriate action.
If the input is invalid, the assistant informs the user and requests valid input.
This logic can be represented using conditional statements such as IF, ELSE IF, and ELSE. It aims to improve reliability, consistency, and error handling.

The actual threshold value and the corresponding actions will depend on the specific requirements of the application.
